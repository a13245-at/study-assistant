# 實驗記錄

## 實驗 A：不貼模板，直接叫 AI 用
- 日期：2026/10/14
- 使用的 AI：chatgpt、豆包
- Prompt：請用我 GitHub 上 study-assistant 倉庫裡的摘要模板，整理下面這段文字：
光合作用是植物利用光能，把二氧化碳和水轉化為有機物並釋放氧氣的過程。它發生在葉綠體中，分為光反應和暗反應兩個階段。

- AI 的回應：chatgpt说无法获取GitHub并请我提供模板;豆包直接给摘要，并提到不存在的tags和reference栏位
- 觀察：两者都没读到我的模板，豆包有幻觉现象
- 結論：AI只读得到我贴给它的内容；要核对输出是否真的照模板做
## 實驗 B：貼上模板 + 課文
- 使用的 AI：chatgpt
- 結果：剛好 5 個重點，格式符合模板
- 觀察：貼了模板後，AI 照做且沒有編造
- 結論：AI 能做到的前提是模板被貼進對話裡
## 實驗 C 結論
- C1 刪角色：標題變中性，易錯概念較淺
- C2 刪字數限制：內容更完整，易錯概念最有深度
- C3 刪易錯概念：輸出完全沒有易錯概念
- 結論：影響最直接的是「輸出項目」那一行（C3），沒寫就沒有；
  角色和限制影響品質與長度，但單次結果有隨機性，需要重複驗證
## 實驗 C1 重跑
- 兩次的 5 個重點內容接近，易錯概念格式與內容不同
- 結論：單次實驗有隨機性；原先「刪角色會讓內容變淺」的判斷證據不足
- 發現：第二次的「錯誤＋正確」格式更實用，但那是 AI 自己選的，沒寫在 Prompt 裡就無法保證
